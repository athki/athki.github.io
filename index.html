Building computable commerce.

Personal shopping agents are the first wave of what is coming: Automated economic decision making at scale. Agents can only go as fast as they can check the rules are followed and their counterparty is trustworthy. That is the emerging bottleneck. I'm interested in building tools and infrastructure that alleviate this bottleneck.

Code verification and cryptography are the building blocks that can make the agentic economy trustworthy. I run the Lean in Munich meetup, and was a guest lecturer in cryptography at Technical University of Munich.

I've built an MCP server that generates compliant invoices via chat, an AI tool that calculates beneficial ownership from private documents in minutes and a simple key in DNS that proves who it's paying. I use cryptography and formal languages to make sure that every decision remains explainable, auditable and within constraints.

This world requires builders that can interface with governments and understand the liabilities that can arise in moving real money. I've done both.
