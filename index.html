Building computable commerce.

Software agents are starting to buy, sell, and sign. They can only go as fast as the rules can be checked. I build the pieces that make the rules computable: a verifier that checks an invoice in milliseconds, an ownership check an agent runs before it pays, and a key in DNS that proves who it's paying. Where the rules can't be computed yet, I work with the people who write them. Each piece leaves evidence that holds up in a dispute.
